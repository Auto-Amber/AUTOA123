Parts of a Micrometer and How to Read Standard (Inch)

A micrometer measures small dimensions with high precision. The outside micrometer is the most common type — used for rotor thickness, shaft diameters, bearing journals, and brake measurements.

Parts: Frame · Anvil · Spindle · Lock nut · Sleeve (barrel) · Thimble · Ratchet stop

Reading a standard (inch) micrometer — 3 steps:

  1. Read the sleeve: Count the number of major divisions exposed beyond the thimble. Each = 0.100". Then count the small tick marks between major lines. Each = 0.025".
  2. Read the thimble: Read the number on the thimble scale aligned with the sleeve reference line. Each graduation = 0.001".
  3. Add them together: e.g., 2 major + 1 small + 17 thimble = 0.200 + 0.025 + 0.017 = 0.242"
A vernier scale adds a fourth reading of 0.0001" (one ten-thousandth) for even higher precision. Read the vernier line that aligns with a thimble graduation and add it to the total.

Reading a Metric Micrometer

A metric micrometer works on the same principle — but the scales are in millimeters.

Reading a metric micrometer — 3 steps:

  1. Read the upper sleeve line: Count whole millimeter marks exposed. Each = 1.00 mm.
  2. Read the lower sleeve line: If a mark is visible below the reference line between whole mm marks, add 0.50 mm.
  3. Read the thimble: Each graduation = 0.01 mm. Read the line aligned with the sleeve reference line.
Example: Upper sleeve shows 7 marks (7.00 mm) + lower sleeve shows one additional mark (0.50 mm) + thimble reads 23 (0.23 mm) = 7.73 mm

Micrometer Care and Technique

Proper technique:

  • Always zero the micrometer before measuring — close spindle onto anvil (or a standard) and verify it reads zero. If off, use the spanner wrench to adjust the sleeve.
  • Use the ratchet stop (not the thimble) for the final snug contact — ensures consistent, repeatable force
  • Measure in at least three locations around a rotor or journal to detect taper and out-of-round
  • Lock the micrometer with the lock nut before removing it from the part
  • Read the measurement before unlocking and removing

Common mistakes:

  • Overtightening: Springing the frame — affects accuracy and damages the tool
  • Measuring on a hot rotor: Metal expands with heat — always measure cold
  • Misreading the 0.025" marks: The most common standard micrometer error — count carefully
  • Forgetting to zero: All measurements from an unzeroed mic are wrong by the same amount
Rotor thickness variation (parallelism): Measure at 8 equally spaced points around the rotor. Maximum allowable variation is typically 0.0005" (standard) or 0.013 mm (metric). Thickness variation causes brake pedal pulsation.
